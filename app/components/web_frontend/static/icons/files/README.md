File-type marks.

Paths from simple-icons (CC0-1.0), recoloured to each product's own
brand colour so a list of paper reads the way it does in any file
manager. Vendored rather than fetched: an icon that needs the network
is an icon that is missing on the one screen somebody is offline for.

Trademarks belong to their owners; these identify a FILE FORMAT, which
is what the marks are for.
